คำแนะนำและการใช้งาน

  • สามารถพิมพ์ชื่อพนักงานลงในช่องแถวซ้ายมือได้โดยตรง ระบบจะบันทึกข้อมูลอัตโนมัติ
  • กดปุ่ม ข้างชื่อพนักงาน เพื่อคัดลอกรูปแบบกะของพนักงานคนนั้นไปยังอีกคน
  • ใช้นาวิเกเตอร์ < สัปดาห์ > เพื่อสลับดูและจัดตารางงานของสัปดาห์อื่นล่วงหน้า
  • ข้อมูลจะถูกบันทึกไว้บนเว็บบราวเซอร์ของคุณโดยอัตโนมัติ (Local Storage)

การจัดการข้อมูล

คืนค่าเริ่มต้น หรือ ล้างตารางงานทั้งหมด

เครื่องมือเติมกะอัตโนมัติ

การดำเนินการนี้จะเขียนทับตารางกะในสัปดาห์ปัจจุบันตามเงื่อนไขที่เลือก

บันทึกและส่งออกข้อมูล

สร้างลิงก์ส่งให้พนักงานกรอกข้อมูล

คัดลอกลิงก์หรือใช้ QR Code ด้านล่างนี้ ส่งเข้า LINE หรือแชตกลุ่มเพื่อให้พนักงานเปิดเข้ามาดูและกรอกกะงานประจำสัปดาห์ได้ทันที

สแกน QR Code เพื่อเปิดกรอกกะบนมือถือ สามารถบันทึกหรือแคปรูป QR Code ไปส่งใน Line กลุ่มได้
ข้อแนะนำการนำไปใช้งานบนเว็บ (Online Host): หากต้องการเปิดให้พนักงานทุกคนกดเข้าผ่านอินเทอร์เน็ตได้ตลอด 24 ชม. สามารถนำไฟล์ index.html ไปอัปโหลดขึ้นบริการโฮสต์ฟรี เช่น GitHub Pages, Netlify หรือ Vercel เพื่อสร้างลิงก์เว็บไซต์ประจำทีมได้ทันที
